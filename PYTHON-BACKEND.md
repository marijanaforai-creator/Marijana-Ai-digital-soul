# Python backend foundation

Ovaj repozitorijum zadržava postojeći HTML/CSS/JavaScript frontend i postojeće JavaScript API funkcije.

Prvi Python sloj je namerno izolovan:

- Endpoint: /api/python-health
- Runtime: Python + FastAPI
- Trenutna funkcija: health check
- Nema izmene postojećih stranica ili API funkcija.

Sledeće funkcije uvodimo tek nakon uspešnog preview testa, i to tamo gde Python daje jasnu prednost: OCR, obrada dokumenata, obrada podataka ili složenija AI logika.
